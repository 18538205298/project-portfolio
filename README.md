## 交流重点

每个项目分别列出业务场景、功能模块、技术结构与可讨论问题。团队分工、个人贡献、第三方依赖和具体效果可结合源码与演示展开说明。

这里以已有项目的功能整理为主。研究复现、实习相关内容与第三方工程另行核对归属和公开范围。

## 展示边界

- 功能描述与性能指标分别确认，性能数据以可复查的测试记录为依据。
- 算法题与课程练习归入学习记录；第三方课程、论文、题目和依赖保留原有归属。
- 本展示集采用新建内容，展示材料与原始工程分开维护。
- 公开页面可被任何访客阅读与复制；完整工程的访问范围单独安排。
